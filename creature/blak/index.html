Blak

monster · Finland · Nordic

Not independently attested in folklore literature. No pike spirit named 'Blak' exists in Finnish mythology. The description grafts an invented name onto the genuine Kalevala motif of the giant pike whose jawbone Väinämöinen used to make the first kantele; that pike is not a named, personalized being.
