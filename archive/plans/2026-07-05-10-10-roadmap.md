# 10/10 Roadmap — Whispering Lore

## Goal

Bring all four evaluation perspectives (User, Researcher, Academic, Folklorist) to a 10/10 score through four tiers of focused, prioritized work.

## Current Baseline

| Perspective | Score | Critical Weakness |
|-------------|-------|-------------------|
| User | 7/10 | No imagery, shallow quiz, empty states |
| Researcher | 5/10 | 71% unknown sources, 15.6% AI templates, 100% missing backlinks |
| Academic | 4/10 | No methodology, no versioning, 2.6% verified |
| Folklorist | 6/10 | AI fun_facts, Nordic-only quiz, inconsistent regions |

## Guiding Principles

1. **Data first** — content quality improvements have multiplicative impact across all perspectives
2. **Transparency** — flag what is known vs unknown rather than pretending completeness
3. **Respect existing architecture** — shimmer shard system, IIFE pattern, existing tests
4. **Test every change** — current 236/237 pass rate must hold or improve
5. **No regressions** — all existing functionality preserved

## Tier 1: Foundation — Critical, Low-Medium Effort

### T1.1 Replace 574 AI-template descriptions
- **Estimate:** 2-3 weeks
- **Who:** Content pass
- **Scope:** The ~574 creatures (15.6%) whose `description`, `appearance`, or `behavior` fields contain generic patterns like "X is a legendary creature from ancient folklore and mythology, appearing in the traditional stories..."
- **Approach:** Generate culture-specific replacements using the creature's region, type, and existing metadata. Each replacement must contain at least one concrete cultural fact (geography, role, associated tradition).
- **Validation:** Before/after word count comparison, manual spot-check of 50 entries across regions, no "template" patterns remain.
- **Impact:** Researcher 5→7, Academic 4→6, Folklorist 6→8

### T1.2 Build bidirectional story-creature index
- **Estimate:** 2-3 days
- **Who:** Script + data update
- **Scope:** Currently 100% of creature `stories` arrays are empty, despite stories already referencing creatures by slug. A script extracts creature refs from `data/datasets/stories.json`, inverts the map, and populates each creature's `stories` array.
- **Approach:** Single Node.js script that reads stories.json, builds `Map<slug, storyId[]>`, then patches creatures.json. Regenerate shards after.
- **Validation:** Zero creature entries with empty stories array when referenced by at least one story.
- **Impact:** Researcher 6→7, Academic 5→6

### T1.3 Replace 3,047 AI fun_facts with real folklore facts
- **Estimate:** 2 weeks
- **Who:** Content pass, parallelizable by region
- **Scope:** Currently 3,047/3,546 fun_facts are marked `fun_fact_generated: true`. Only 499 are genuine.
- **Approach:** Regional content specialists review entries grouped by region. Each AI-generated fact is either replaced with a verified folklore fact or the field is marked as "Not documented."
- **Validation:** `fun_fact_generated` count drops from 3,047 to 0. Each remaining fun_fact has a source note.
- **Impact:** Folklorist 6→7, User 7→8

### T1.4 Add methodology page
- **Estimate:** 1 day
- **Who:** Developer + content
- **Scope:** New page explaining how the dataset was compiled: sources used, inclusion criteria, translation approach, editorial standards, known limitations.
- **Approach:** New link in footer nav. Static HTML page following about.html pattern with page-hero and content sections. Covers: data sources, verification process, AI usage disclosure, how to contribute.
- **Validation:** Link exists in footer, page renders with same theme, content covers all methodology questions from the analysis.
- **Impact:** Academic 4→6

### T1.5 Add date-stamped versioning
- **Estimate:** 2 days
- **Who:** Developer
- **Scope:** Dataset version number + last-updated timestamp per entry. Exposed in JSON-LD structured data and visible in creature/story detail views.
- **Approach:** Add `version` and `lastUpdated` fields to the dataset manifest. Each creature gets `lastUpdated` from its file modification time or a batch script. Display "Last updated: YYYY-MM-DD" in detail footer.
- **Validation:** Every detail view shows a date. Manifest includes a version string.
- **Impact:** Academic 5→7

### T1.6 Global quiz expansion (15 → 100+ questions)
- **Estimate:** 1-2 weeks
- **Who:** Developer + content
- **Scope:** Current quiz has 15 questions, all Nordic. Expand to at least 100 questions covering Africa, Asia, Americas, Pacific, Middle East, and Europe.
- **Approach:** Automated question generation from creature data (prompt → choices → correct answer using creature facts), plus hand-curated questions for quality. Distribute evenly across 6 difficulty levels and all regions.
- **Validation:** 100+ questions, at least 5 countries per major region represented, no duplicate prompts. Existing quiz tests still pass.
- **Impact:** User 7→8, Folklorist 6→8

### T1.7 Source quality badges in detail view
- **Estimate:** 1 day
- **Who:** Developer
- **Scope:** Display `source_quality` field visually on creature detail view as a colored badge: "Verified" (green), "Oral Tradition" (amber), "Literary" (blue), "Unknown" (grey).
- **Approach:** Badge rendered in `detail-meta` row alongside type/country/region. CSS classes for each quality tier.
- **Validation:** Badge appears on every creature detail. Colors match the tier system. Tests pass.
- **Impact:** Researcher 5→6, Academic 5→6

### T1.8 Fix region inconsistencies
- **Estimate:** 1 day
- **Who:** Developer
- **Scope:** Clean up ~50 entries where region names are inconsistent (e.g. "Pacific" vs "East Asia and Pacific" used interchangeably for the same country).
- **Approach:** Script that normalizes region values against the canonical list in `data/datasets/geo-regions.json`.
- **Validation:** No creature or story has a region value outside the canonical set.
- **Impact:** Folklorist 6→7, Researcher 6→7

## Tier 2: Transformation — Medium-High Effort

### T2.1 Source quality verification campaign
- **Estimate:** 3-4 months (parallelizable)
- **Who:** Research content pass
- **Scope:** Systematically verify source quality for all 3,668 creatures. Upgrade from 2.6% verified to 50%+.
- **Approach:** Region-by-region review. Each entry's existing `source` field checked against reliable references. Entries without verifiable sources are marked transparently rather than as "unknown."
- **Validation:** Minimum 50% of entries marked "verified" or "literary" with a named source.
- **Impact:** Academic 6→9, Researcher 7→9

### T2.2 Auto-link related creatures
- **Estimate:** 2-3 days
- **Who:** Developer
- **Scope:** 90% of creatures have empty `related` arrays. Automatically populate based on shared region + type + tradition.
- **Approach:** Script groups creatures by (region, type) clusters, ranks by attribute overlap, populates top 5 related slugs per entry.
- **Validation:** At least 1,800 creatures have non-empty related arrays after deduplication.
- **Impact:** Researcher 6→7

### T2.3 Citation export
- **Estimate:** 1 week
- **Who:** Developer
- **Scope:** BibTeX, MLA, and APA citation generation per creature and story entry.
- **Approach:** JS function that takes structured entry data and outputs formatted citation string. Render as "Cite this" button in detail footer with copy-to-clipboard popover.
- **Validation:** All three formats generate valid citations. Copy button works. Tests cover format correctness.
- **Impact:** Academic 6→8, Researcher 7→8

### T2.4 Complete placeholder stories
- **Estimate:** 3-5 days
- **Who:** Content pass
- **Scope:** 9 stories currently have "A placeholder entry representing the folklore traditions of [country]" summaries. Replace with real content.
- **Approach:** Research folklore from each small island country. Write full story entries following the existing story schema (summary, full_text, themes, moral, source).
- **Validation:** Zero stories contain "placeholder" in their summary field.
- **Impact:** Folklorist 7→8

### T2.5 Random creature button
- **Estimate:** 1 day
- **Who:** Developer
- **Scope:** "Random Creature" and "Random Story" buttons, plus a "Surprise Me" that picks either.
- **Approach:** Pick random index from creature/story pool. Navigate to detail view or link to bestiary detail. Button in hero area.
- **Validation:** Click navigates to a valid, existing entry every time.
- **Impact:** User 7→8

### T2.6 My Lore empty state
- **Estimate:** 0.5 day
- **Who:** Developer
- **Scope:** When My Lore page has no saved favorites or bookmarks, show a helpful message explaining how to add them (with links to bestiary/stories).
- **Approach:** In mylore.js, check for empty arrays and render guidance section instead of empty grids.
- **Validation:** Fresh visit shows guidance. After saving favorites, guidance disappears.
- **Impact:** User 7→8

### T2.7 Living tradition flag
- **Estimate:** 2 days
- **Who:** Developer + content
- **Scope:** Add boolean field `living_tradition` to creature schema. Display as a badge in detail view when true.
- **Approach:** New field in data model. Script to bulk-assign initial values based on region/type heuristics. Manual review for accuracy.
- **Validation:** Flag appears in detail view for entries where true. Schema is consistent.
- **Impact:** Folklorist 7→8

### T2.8 Source-type tags
- **Estimate:** 3 days
- **Who:** Developer + content
- **Scope:** Add `source_type` field: "oral_tradition", "literary", "archaeological", "syncretic", "unknown". Displayed as badges.
- **Approach:** Extend creature schema. Bulk-assign based on existing metadata patterns. Manual review.
- **Validation:** Every creature has a source_type value. Badges render correctly.
- **Impact:** Folklorist 7→8, Academic 6→7

## Tier 3: Distinction — High Effort, Premium Feel

### T3.1 Cultural-appropriate creature visuals
- **Estimate:** 2-4 weeks
- **Who:** Developer + designer
- **Scope:** Replace the generic rune SVG placeholder with region-themed SVGs or CSS-based glyphs. At minimum: one distinct icon per cultural region (32 sets).
- **Approach:** SVG sprite per region, selected via creature's `region` field. Falls back to generic diamond logo for unknown regions.
- **Validation:** Every creature card shows a region-appropriate icon. Performance measured (no layout shift, bundle size impact < 50KB).
- **Impact:** User 8→10, Folklorist 7→9

### T3.2 Dataset DOI + Zenodo versioning
- **Estimate:** 1 week
- **Who:** Developer
- **Scope:** Publish dataset to Zenodo with automated re-publishing on significant data changes. DOI included in JSON-LD and footers.
- **Approach:** GitHub Action that zips data/ directory and publishes to Zenodo API on tagged releases. DOI displayed on about page and in entry metadata.
- **Validation:** DOI resolves to current dataset version. Each tag creates a new version on Zenodo.
- **Impact:** Academic 6→9

### T3.3 Pronunciation guides
- **Estimate:** 2-4 weeks
- **Who:** Content + developer
- **Scope:** IPA pronunciation for creature names. Optional audio via TTS or recordings.
- **Approach:** Add `pronunciation_ipa` and `pronunciation_audio` optional fields to creature schema. IPA from scholarly references. Audio from TTS for major entries.
- **Validation:** 500+ entries have IPA. Top 100 entries have audio.
- **Impact:** Folklorist 7→9, User 8→9

### T3.4 Reading progress tracking
- **Estimate:** 1 week
- **Who:** Developer
- **Scope:** Track which creature/story detail pages a user has opened (localStorage). Show "X of Y explored" progress.
- **Approach:** LoreBox storage (existing) tracks viewed slugs. Progress bar on My Lore page.
- **Validation:** Viewing a creature marks it as explored. Count updates. Tests for storage interaction.
- **Impact:** User 8→9

### T3.5 Editorial board / contributors
- **Estimate:** 1 day
- **Who:** Content
- **Scope:** Add editorial board section to about page or new page. List contributors, reviewers, and subject-matter experts who have vetted content.
- **Approach:** Static section on about page or separate contributors page.
