# append-research-history

## Purpose
Automatically log each completed research session into `data/research-history.md`.

## Behavior
1. Create a new session block using the template in `research-history.md`.
2. Include:
   - Session ID (timestamp)
   - Target entity
   - Known sources used
   - Missing information identified
   - Search strategies used
   - Search queries executed
   - New sources discovered
   - Extracted information
   - Contradictions found
   - Translation and normalization notes
   - Confidence score assigned
   - Follow-up tasks
3. Append the block to the bottom of the “Completed Sessions” section.

## Notes
- Ensures all research is tracked.
- Prevents repeated work.
- Builds a long-term research memory.
