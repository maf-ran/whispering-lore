Research and rewrite 35 folklore descriptions for West African creatures, focusing on real attestation and cultural accuracy.

## Research Priorities
**High Priority - Known figures:**
- Abiku (Yoruba)
- Mami Wata (various West African cultures)
- Raven Deity of Ashanti
- Kanaga Spirits (Dogon)

**Medium Priority - Questionable:**
- Arọ̀ni (may be misattributed)
- Moose spirits (likely Africanized creatures)
- Marabout (Islamic figure, may be mischaracterized)

**Low Priority - Highly Problematic:**
- Raven Giant of Yoruba
- Moose Trickster (Cree in Nigeria - culturally inconsistent)

## Research Strategy
1. Start with high-priority items using exa-search for current scholarship
2. Check Wikipedia, academic databases, institutional websites
3. Cross-reference multiple sources for each creature
4. Verify authenticity vs. African diaspora appropriations
5. Preserve alternative names and cultural context
6. Write authentic descriptions (150-400 chars) without forbidden phrases

## Verification Rules
- If no attestation found: set attested: false, quality: "poor", note discrepancy
- Correct country/culture if wrong (but keep slug)
- Preserve transliterations and regional variants
- Exclude template phrases: "extends beyond simple folklore", "traits including", "This entity demonstrates", "represents an important figure", "influencing cultural practices", "serves as", "embodies the"

## Output Requirements
- 35 entries in same order as input
- Valid JSON with all required fields
- Description: 150-400 characters, no forbidden phrases
- Research-based, culturally accurate content
- Honest attestation status for all items
